# Sain Motors · Автомашины танилцуулга

Постерын QR кодоор нээгдэх, утсанд зориулсан каталог. Node.js 20 ба түүнээс дээш хувилбараар `npm start` ажиллуулаад [localhost](http://127.0.0.1:3221/) дээр үзнэ. Нэмэлт сан суулгах шаардлагагүй.

## PDF холбох

1. Баталгаажсан PDF файлыг `brochures/` фолдерт байрлуулна. Жишээ нь `jetour-t2-luxury.pdf`.
2. `vehicles.js` дотор тухайн загварын `pdf: null` утгыг `pdf: "jetour-t2-luxury.pdf"` болгож өөрчилнө.
3. Каталогийг шинэчилж, тухайн загварын картыг дараад боршур шинэ табд нээгдэж буйг шалгана.

PDF холбогдоогүй загварын зураг, нэр, хувилбар болон борлуулалтын утсыг каталог дээр харж болно. Эх материал нь өмнөх Sain Motors дижитал танилцуулгын есөн зураг, одоогийн сайтын лого, постерт байгаа борлуулалтын утас юм.

Хостинг дээр `index.html`, `styles.css`, `app.js`, `vehicles.js`, `assets/`, `brochures/`-ийг нэг түвшинд байрлуулна. Хэрэглэгчийн QR кодод нийтэд нээлттэй HTTPS хаяг ашиглана.
